This document provides supplemental materials for the manuscript entitled ``Poriferous Surface Coverage of Networked Euler-Lagrange Systems via Poly-Annulus Conformal Mapping'' by Xun Feng, Chao Zhai, Chuan-Ke Zhang, and Yong He. It is composed of three parts. The first part presents some theoretical results, including key definitions and the derivation process of the mapping. The second part provides simulation results on the poriferous surface and relevant discussions, which include the analysis of computational cost, stability, and robustness. The third part discusses the changes required in the theoretical proof when the dynamics are reduced to a single integrator. It is worth noting that the notations for theorems, lemmas, propositions, and citations in the supplementary material are consistent with those in the main text.
